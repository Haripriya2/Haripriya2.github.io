# Haripriya Nair — Research Website

A responsive, single-page personal research website built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — layout, typography, and responsive styles
- `script.js` — automatically updates the footer year
- `cv.pdf` — optional CV file to add

## Before publishing
1. Search `index.html` for `YOUR_EMAIL@example.com`, `YOUR_GITHUB_USERNAME`, and `YOUR_LINKEDIN_USERNAME` and replace them with your actual details.
2. Add your CV PDF to this folder and name it `cv.pdf`, or remove the CV link from the page.
3. Review all biography and project wording for accuracy. Project concepts are explicitly labeled as ideas, not completed work.

## Publish with GitHub Pages
1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, visit `https://YOUR_GITHUB_USERNAME.github.io`.

You can edit the text directly in `index.html`. Keep the three website files in the same folder so the CSS and JavaScript load correctly.
